Machine Learning Models for Spam Classification

1. Naive Bayes

Definition: Probabilistic classifier based on Bayes theorem with strong independence assumptions.

How it works: Calculates the probability of a message being spam/ham based on feature likelihoods.

Mathematical: P(Class|Features) ∝ P(Class) * Π P(Feature|Class)

Best for: Text classification, works well with high-dimensional sparse data.

Example: "Win a free iPhone" → High probability of spam

2. Logistic Regression

Definition: Linear model that predicts probability of a binary outcome using sigmoid function.

How it works: Computes weighted sum of features → applies sigmoid → outputs probability.

Mathematical: P(y=1|x) = 1 / (1 + e^-(w·x + b))

Best for: Linearly separable problems, interpretable coefficients.

Example: "Meeting at 5 pm" → Likely ham

3. Random Forest

Definition: Ensemble of decision trees using bagging and majority voting.

How it works: Multiple trees are trained on random subsets → predictions aggregated.

Mathematical: Majority vote: y = mode(T1(x), T2(x), ..., Tn(x))

Best for: Non-linear patterns, robust to overfitting, can handle high-dimensional data.

Example: "Special discount, call now!" → Likely spam

4. Gradient Boosting

Definition: Ensemble of weak learners (trees) built sequentially to correct previous errors.

How it works: Each new tree minimizes residual errors of previous ensemble → weighted sum of trees.

Mathematical: F_m(x) = F_{m-1}(x) + learning_rate * h_m(x)

Best for: High accuracy, complex datasets, sensitive to overfitting if not tuned.

Example: "Congratulations! Claim your prize" → Likely spam
